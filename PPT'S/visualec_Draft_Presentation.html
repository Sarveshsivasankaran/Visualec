Base MVP
MVP Done Scope

A simple ESP32-S3-only demonstrator for zone-based switching.

This prototype removes Raspberry Pi, local server and DVR processing. It proves the core idea with a direct camera and low-voltage bulbs.

ESP32-S3 with supported camera module
Lightweight person/pedestrian detection
3 virtual zones across the camera frame
3 relay outputs controlling 3 low-voltage bulbs
ON confirmation + OFF delay to prevent flickering

Tech Stack
Under The Hood

Every part earns its place on a single low-cost board.

No server rack, no GPU, no subscription — the whole pipeline runs on-device.

Sense

Camera Module

OV2640 / OV5640 feeding raw frames directly into the microcontroller — no separate video pipeline to maintain.

Think

ESP32-S3

Dual-core brain that handles capture, inference, zone mapping and timing without offloading to a server.

Detect

Presence Model

A lightweight, quantised person-detector — presence only, no identity, no face data stored.

Act

Relay + Timers

ON-confirmation and OFF-delay logic drives 3 relays so loads switch cleanly, without flicker.

Why It Matters
The Problem With Static Lighting

Most rooms light the whole space for whoever's in one corner of it.

Occupancy-aware control only asks one question per zone: is someone actually there? Independent, evidence-based industry studies commonly cite meaningful lighting-energy reductions from this kind of zoned, presence-based switching — the exact number always depends on the room and usage pattern.
